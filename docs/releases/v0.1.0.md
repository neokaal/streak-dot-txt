# Streak.txt v0.1.0 — Hearth Pheasant

The first desktop release of Streak.txt turns a directory of plain-text streak
files into a compact daily switchboard. Controls stay in familiar positions,
completed streaks are immediately recognizable, and the four-color Dusty4
palette keeps the interface quiet and focused.

Streak.txt works offline and keeps your data in your local `streaks` directory.
This release includes native installers for macOS on Apple Silicon and 64-bit
Windows.

## Highlights

- Fast, fixed-position controls for up to 25 immediately visible streaks
- One-click daily ticking with current, best, and completion-rate statistics
- Portable streak ordering stored alongside the streak files
- Shared, hardened file handling across the desktop, web, CLI, and Tkinter apps
- Automatic local-service startup, shutdown, and troubleshooting logs

## Installation note

These initial builds are not signed with Apple or Microsoft developer
credentials. macOS requires the documented Gatekeeper override, and Windows
may display a Microsoft Defender SmartScreen warning. No corporate signing
credentials are used.
